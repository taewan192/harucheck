# 하루체크 사용안내

하루체크는 브라우저 웹앱입니다. `node scripts/start.mjs`로 실행한 후 `http://127.0.0.1:5173/harucheck.html`을 엽니다. 휴대폰 크기의 미리보기는 `/mobile-preview.html`입니다. 실행과 수정 방법은 [README](../README.md)를 참고하세요.

## 시작과 필수 알림 권한

처음에는 **알림 허용하고 시작**을 누르고 브라우저의 알림 권한을 허용합니다. 권한이 없거나 차단된 환경에서는 일정 화면에 들어갈 수 없습니다. 권한은 사용자가 브라우저에서 직접 허용해야 하며 앱이 강제로 켤 수는 없습니다.

알림을 차단했다면 브라우저의 사이트 설정에서 허용한 후 **권한 다시 확인**을 누릅니다. 설정과 언어 선택은 권한을 허용하기 전에도 사용할 수 있습니다. 사용 중 권한이 해제되면 일정 화면이 다시 잠깁니다. 기존 일정은 삭제하지 않습니다.

알림은 지원 브라우저와 HTTPS 환경이 필요합니다. 개발용 `localhost`와 `127.0.0.1`은 지원되지만 HTML 파일을 직접 여는 `file:` 환경에서는 이용할 수 없습니다. iPhone에서는 HTTPS로 제공된 앱을 Safari에서 홈 화면에 추가한 후 실행해야 합니다. 홈 화면 실행용 매니페스트와 아이콘이 포함되어 있습니다. 다른 기기에서 사용하려면 HTTPS 호스팅이 별도로 필요합니다.

## 화면 모드와 언어

오른쪽 위 **설정**에서 화이트·다크 모드와 언어를 선택합니다. 선택한 설정은 같은 브라우저와 주소에서 다시 열 때 유지됩니다.

지원 언어는 한국어, 영어, 일본어, 중국어 간체, 러시아어, 태국어, 베트남어, 힌디어, 프랑스어, 필리핀어입니다. 날짜·요일·버튼·오류·알림 문구도 선택한 언어로 표시합니다. 직접 입력한 일정 이름과 소리 파일 이름은 번역하거나 변경하지 않습니다.

**설정 → 테스트 알림**으로 기본 알림을 확인할 수 있습니다.

## 일정 관리

1. 달력 위 연도를 눌러 2026년·2027년과 원하는 달을 선택합니다.
2. 날짜를 선택한 뒤 **일정 추가**를 누릅니다. 이름과 날짜는 필수이고 시간은 선택입니다.
3. 일정 옆 **완료**, **실패**로 상태를 바꿉니다. 선택된 버튼을 다시 누르면 예정으로 돌아갑니다.
4. 연필 버튼에서 이름·날짜·시간·알림·소리·진동·상태를 수정할 수 있습니다. **일정 삭제**를 누르면 확인 후 삭제됩니다.

모바일 달력에는 날짜당 일정 제목 2개와 나머지 개수가 표시됩니다. 긴 제목은 달력에서 줄여 표시하며 선택한 날짜의 목록에서는 전체 이름을 확인할 수 있습니다.

## 일정별 알림

일정 추가·수정 화면의 **알림**에서 다음 중 하나를 선택합니다.

- 알림 없음
- 일정 시작할 때
- 30분 전부터 300분 전까지, 30분 간격
- 직접 설정: 알림 받을 날짜와 시간을 분 단위로 지정

시작 시점·몇 분 전 알림에는 일정 시간이 필요합니다. 직접 설정은 일정 시간이 없어도 사용할 수 있습니다. 새 알림이나 변경한 알림은 미래 시간을 선택해야 합니다. 알림 없음을 선택하면 소리·진동 설정은 비활성화됩니다.

### 소리와 진동

**소리 알림**, **진동 알림**을 일정마다 켜거나 끌 수 있습니다. **미리 듣기·진동**으로 확인하고 **중지**로 멈춥니다.

**소리 파일 가져오기**에서 기기의 재생 가능한 오디오 파일을 선택할 수 있습니다. 파일 크기는 최대 10MB이며 브라우저가 실제로 재생할 수 있는 형식이어야 합니다. 파일을 고른 뒤 일정을 저장해야 파일도 저장됩니다. 취소하면 선택한 파일은 저장하지 않습니다.

파일은 서버로 전송하지 않고 기기의 브라우저 내부 `IndexedDB`에 보관합니다. 수정 화면에서 저장한 파일 이름을 확인할 수 있고 **기본음으로 변경**하면 기본 알림음을 사용합니다. 파일이 사라졌거나 재생할 수 없으면 내장 기본음으로 전환합니다. 파일 저장에 실패하면 해당 일정 변경을 저장하지 않습니다.

앱이 열려 있으면 선택한 파일이나 내장 기본음이 재생됩니다. 재생은 최대 30초이며 **중지** 또는 알림 확인으로 멈춥니다. 시스템 알림음은 기기의 알림 설정을 따릅니다. 웹앱은 휴대폰 시계 앱의 기본 알람음을 직접 읽거나 선택할 수 없습니다. 브라우저가 자동 재생을 막으면 미리 듣기를 눌러 활성화해야 합니다.

진동은 지원 기기에서만 동작합니다. iPhone 등 웹 진동을 지원하지 않는 기기에서는 앱이 직접 진동을 발생시킬 수 없습니다. 시스템 알림의 소리·진동·무음 및 방해 금지 동작은 OS와 브라우저 설정에 좌우됩니다.

### 작동 범위

**이 버전은 앱이 실행 중일 때 알림 시각을 확인합니다.** 앱 종료·절전·백그라운드 정지·무음 모드에서 정시 소리와 진동을 보장하지 않습니다. 종료 후에도 확실한 예약 알람이 필요하면 네이티브 앱 알람 기능 또는 별도 예약·푸시 서버가 필요합니다. 홈 화면에 추가하는 것만으로 이 제한이 없어지지는 않습니다.

알림 시각에는 화면 위쪽에도 알림이 표시됩니다. 중복 알림은 억제하며 최근 24시간 안에 놓친 알림은 다시 열 때 확인합니다. 완료·실패로 바꾸거나 일정을 삭제하면 그 일정의 알림이 중지됩니다.

## 기기 캘린더로 내보내기

일정 수정 화면에서 **기기 캘린더에 추가 (.ics)**를 누릅니다. 내보내기는 저장된 일정의 복사본이며 기기 캘린더에서 알림을 확인해야 합니다. 이후 앱의 수정·삭제가 자동 반영되지 않습니다. 개인 소리 파일·진동 설정은 내보내지 않습니다.

시간 있는 일정은 1시간 길이로, 시간 없는 일정은 종일 일정으로 내보냅니다. 완료·실패 일정의 내보내기에는 알림이 없습니다.

## 저장과 데이터

일정과 환경설정은 `localStorage`, 소리 파일은 `IndexedDB`에 저장됩니다. 브라우저 데이터를 지우면 일정과 파일이 사라질 수 있습니다. 다른 기기·브라우저·주소는 별도의 저장 공간을 사용합니다. GitHub에는 코드만 저장하며 일정·소리 파일을 수집하거나 동기화하지 않습니다. 전체 백업·복원은 아직 제공하지 않습니다.
