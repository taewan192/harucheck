# 하루체크 사용안내

저장소 최상위의 `harucheck.html`을 브라우저에서 열면 사용할 수 있습니다. 설치형 APK/IPA가 아닌 브라우저 웹앱이며, 파일을 직접 열 때는 인터넷 연결이나 회원가입이 필요하지 않습니다. 개발 서버 실행과 소스 수정 방법은 [README](../README.md)를 참고하세요.

## 일정 관리

1. 달력 위 연도를 눌러 2026년·2027년과 원하는 달을 선택합니다.
2. 날짜를 선택한 뒤 **일정 추가**를 누릅니다. 이름과 날짜는 필수이고 시간은 선택입니다.
3. 일정 옆 **✓ 완료**, **✕ 실패**로 상태를 바꿉니다. 선택된 버튼을 다시 누르면 예정으로 돌아갑니다.
4. 연필 버튼에서 이름·날짜·시간·알림·상태를 수정할 수 있습니다. 같은 화면의 **일정 삭제**를 누르면 확인 후 삭제됩니다.

일정이 있는 날짜에는 제목 라벨이 표시됩니다. 여러 일정은 시간순으로 아래에 쌓이고 시간이 없는 일정은 마지막에 표시됩니다. 긴 제목은 줄바꿈하며 완료·실패 라벨에는 ✓·✕가 함께 표시됩니다.

오른쪽 위 **화이트 / 다크** 버튼으로 화면 모드를 바꿀 수 있습니다. 선택한 모드는 같은 브라우저와 주소에서 다시 열 때 유지됩니다.

## 알림 설정

일정 추가·수정 화면의 **알림**에서 다음 중 하나를 선택합니다.

- **알림 없음**
- **일정 시작할 때**
- **30분 전~5시간 전**: 30분 간격으로 선택
- **직접 설정**: 알림 받을 날짜와 시간을 분 단위로 지정

시작 시점·몇 분 전 알림은 일정 시간이 있어야 합니다. 직접 설정은 일정 시간이 없어도 사용할 수 있습니다. 새로 설정하거나 알림 시각을 바꿀 때는 미래 시간을 선택해야 합니다.

일정 날짜·시간을 수정하면 ‘몇 분 전’ 알림도 다시 계산됩니다. 직접 설정한 알림은 지정한 날짜·시간을 유지합니다. 완료·실패로 표시하거나 일정을 삭제하면 그 일정의 알림은 중지됩니다.

알림 시간이 되면 화면 위쪽에 **일정 알림**이 표시됩니다. **알림 수신 설정 → 알림 미리보기**로 표시 방식을 확인할 수 있습니다. 이미 보낸 알림은 반복 표시하지 않으며 다시 열었을 때 최근 24시간 안에 놓친 알림이 있으면 표시합니다.

**이 버전의 알림은 앱이 실행 중일 때 동작합니다.** 앱 종료·휴대폰 절전·백그라운드 정지 상태에서는 정시 알림을 보장하지 않습니다. 앱을 열어 두어도 브라우저의 타이머 제한에 따라 지연될 수 있습니다.

- HTML 파일을 직접 열면 앱 안에 알림을 표시합니다.
- `localhost` 또는 HTTPS 등 지원 환경에서는 **브라우저 알림 허용**을 눌러 시스템 알림을 사용할 수 있습니다. OS·브라우저 권한과 설정에 따라 표시·소리 동작이 달라집니다.
- 시스템 알림용 `harucheck-sw.js`는 HTML과 같은 폴더에 있어야 합니다. 이 파일은 알림을 표시하는 용도이며 종료된 앱을 깨워 알림을 예약하지 않습니다.

## 기기 캘린더로 내보내기

저장한 일정의 수정 화면에서 **기기 캘린더에 추가 (.ics)**를 누른 뒤 내려받은 파일을 휴대폰이나 컴퓨터의 캘린더로 가져옵니다. 사용하는 캘린더가 알림까지 가져왔는지 확인해주세요.

내보내기는 저장된 값만 사용합니다. 수정 중인 내용이 있다면 먼저 저장하고 다시 열어 내보내세요. 내보낸 일정은 복사본이므로 이후 하루체크에서 수정·삭제한 내용이 기기 캘린더에 자동으로 반영되지 않습니다.

종료 시간을 입력하는 기능이 없으므로 시간 있는 일정은 내보낼 때 1시간 길이로 설정합니다. 시간 없는 일정은 종일 일정으로 내보냅니다. 완료·실패 일정에는 내보낸 파일의 알림을 설정하지 않습니다.

## 저장과 데이터

일정은 현재 브라우저의 저장 공간(`localStorage`)에 보관됩니다. GitHub 저장소는 코드와 디자인을 보관하며 사용자가 입력한 일정을 수집하거나 동기화하지 않습니다.

다른 기기·브라우저·주소에서는 별도의 저장 공간을 사용합니다. 파일 위치를 바꾸거나 파일 직접 열기에서 로컬 서버로 전환하면 기존 일정이 보이지 않을 수 있습니다. 브라우저 데이터를 삭제하면 일정도 사라질 수 있습니다. 현재 전체 일정 백업·복원 기능은 없습니다.

## Figma 디자인

`design/harucheck-figma.svg`를 Figma 캔버스에 끌어 넣으면 화이트 달력, 다크 달력, 화이트 일정 추가, 다크 일정 수정의 4개 화면을 가져올 수 있습니다. `design/harucheck-design.png`는 미리보기 이미지입니다.

SVG는 벡터·텍스트 기반의 정적 디자인 보드입니다. 클릭 동작과 데이터 저장은 HTML 앱에 구현되어 있으며 Figma 편집 내용은 앱에 자동 반영되지 않습니다. 디자인에 표시된 예시 일정도 실제 앱에 추가되지 않습니다.
